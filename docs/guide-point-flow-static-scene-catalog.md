# guide-point-flow-v2 全量静态路由场景库

## 统计口径

一个**静态路由场景**指一条可以被参数路由选中的配置：根兜底 1 条 + 每个 req_type 的默认配置 58 条 + 每个 (req_type, caller_id) 覆盖 25 条，共 **84 条**。

其中 caller_id=* 表示：该 req_type 已命中，但 caller 没有命中任何该 req_type 下的精确 caller 覆盖；它不表示与所有 caller 专属配置并行执行。

优先级：(req_type, caller_id) 精确命中 → req_type:* 默认 → *:* 根兜底。配置中 req_type=default 是显式业务场景，不是根兜底。

## 使用说明

- 每条记录的 scene_name_list 中，场景名:数字 的数字为配置优先级；-99 表示末位校验场景。
- 降级场景仅在 Apollo scene_degrade_switch 命中且当前层级配置了 degrade_scene_name_list 时启用；否则仍使用正常执行场景。
- 该清单只描述 parameter.conf 的静态路由。map_api、四轮快送、实时预估、DDMQ 消费等会在代码中改写 req_type，需在运行时场景库中以原始请求场景 → 最终执行场景额外记录。
